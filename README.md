# Davide Ferrara

Backend engineer focused on Go, C, Python and Linux.

I like building software close to the system boundary: network servers, developer tools, LLM agents and automation systems. I am especially interested in self-contained agents, local automation and software that is simple enough to inspect, adapt and extend.

## Projects

- [kilo-agent](https://github.com/davide-ferrara/kilo-agent): self-contained, malleable LLM agent runtime in Go.
- [minredis](https://github.com/davide-ferrara/minredis): Redis-compatible TCP server in C with RESP parsing, snapshots and benchmarks.
- [feed-analysis](https://github.com/davide-ferrara/feed-analysis): research project on AI-assisted social media ranking evaluation.
- [wsc](https://github.com/davide-ferrara/wsc): HTTP server in C built from scratch with request parsing, routing and socket handling.
- [picoboy](https://github.com/davide-ferrara/picoboy): Game Boy emulator in C targeting Raspberry Pi Pico 2.
