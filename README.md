# Davide Ferrara

Applied AI / Backend Engineer working with Go, Python and C.

I build AI-enabled products and backend systems, with hands-on work in agent loops, tool calling, multimodal classification, ranking pipelines and network programming.

My Computer Science thesis replicated a CHI '26 study on value-aligned social media ranking. I built the full research system and evaluated it with 10 participants across 2,700 Instagram posts.

Alongside university, I independently delivered three commercial B2B products for an international client, managing the remote workflow from requirements through revisions and hand-off.

## Selected projects

- [Kilo Agent](https://github.com/davide-ferrara/kilo-agent): compact LLM agent runtime in Go with Ollama, multi-step tool execution, streaming, file attachments, web search, Telegram integration and automated tests.
- [Value-aligned social feed ranking](https://github.com/davide-ferrara/feed-analysis): BSc thesis system with a Chrome extension, FastAPI backend and multimodal classification across 19 Schwartz values. Participants identified the value-ranked feed in 72.5% of trials.
- [Bluesky personalised feed generator](https://github.com/davide-ferrara/bluesky-feed-generator): Go application that fetches and classifies posts, then generates feeds from user-defined value weights.
- [MinRedis](https://github.com/davide-ferrara/minredis): Redis-inspired TCP server in C with inline command parsing, RESP replies, concurrent clients, snapshots and benchmarks.

## Other systems projects

- [Meshell](https://github.com/davide-ferrara/meshell): browser-accessible Linux terminal for managing remote machines.
- [WSC](https://github.com/davide-ferrara/wsc): HTTP server in C built from scratch with request parsing, routing and socket handling.
- [Picoboy](https://github.com/davide-ferrara/picoboy): Game Boy emulator in C targeting Raspberry Pi Pico 2.
